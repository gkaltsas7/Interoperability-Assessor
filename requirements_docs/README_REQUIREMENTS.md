# Requirements / Features Roadmap

The active roadmap is:

```text
requirements_docs/implementation_requirements.xlsx
```

It is a simplified requirements/features list derived from the supervisor's feedback. It tracks the core functionality of the tool:

- assessment basis selector,
- locked Interoperable Europe Act and IE Act Guidelines,
- selectable EIF / EIRA sources,
- custom guideline upload and relevance check,
- internal and custom sensitive terms lists,
- two report types,
- and future EIF 4.0 draft support.

The roadmap is intentionally simple and presentation-friendly.
