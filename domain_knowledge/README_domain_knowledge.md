# Assessment reference documents

The legal-basis documents and optional EIRA package here are external institutional publications, **not original work of this repository author**. They were bundled with the research prototype to document the methodology and support reproducibility.

The relevant institutional authorities are the European Union / European Commission / Interoperable Europe. Refer to the corresponding official publications for their terms of use and the most recent versions.

The application keeps paths to these assets in its assessment configuration. It does **not** send the entire content of each PDF as a new live retrieval query for every stage; much of the methodology is encoded in application prompts and pipeline code.

**Public-release check:** confirm redistribution rights for each file. If unsuitable, remove the files from the public repository and link to their official download locations while preserving the configuration/documentation of the expected reference versions.

Private supervisor-provided examples and templates are deliberately **not included** in this public-release package.
